# 关单识别与金额复核

## 提取流程

PDF 优先读取原始文字及坐标，文字不足的页渲染后使用 PP-OCRv5。本地图片支持 PNG、JPG/JPEG/JFIF、BMP、TIF/TIFF、GIF、WEBP，多页文件逐页读取。横放和倒置页面按文字方向选择正确的阅读方向。

每页通常进行一次 OCR。商品表没有读到金额，或可定位商品行数量大于已读金额项数时，裁取商品表的印刷区域使用同一引擎补扫。补扫坐标映射回原页，仅补充缺失文字框；冲突值不覆盖、不推测币种。

## 字段和行定位

表头字段按标签、相邻列和相邻行边界定位。轻微跨框的文字按中心坐标判断归属，减少收货人漏读。商品行以项号和价格栏定位，行起点保留合理文字基线容差，避免串入下一项。过高的斜向水印文字框不参与金额、数量和商品名称解析；商品名称剔除混入的十位商品编码。

## 金额规则

PDF 和 OCR 都核对原页数量、单价与总价。数量与单位作为同一文字组合保存，优先采用能够解释该项目金额的实际计价组合；没有相符组合时保留原值并提示，不用总价除以单价生成数量。舍入容差依据单价印刷小数位计算，整数单价视为精确值。

金额规则不符的分项保留在明细，但不计入可信合计。每页可定位商品行数大于已识别金额项数时标记需关注，提示合计可能不完整。缺少币种的金额不擅自计入某个币种。

表头号码冲突、国别和关别异常同样提示核对。目的国优先按运抵国栏的代码和名称读取；出境关别缺失时可使用表头重复印刷的关区名。提单及放行通知等具有明确特征且不含关单表头的文件提示为非关单。

## 重复与合计

本次批次中报关单号相同的记录视为重复；文件名不参与判断。规范记录按字段完整度、置信度和异常状态选择；去重前和去重后金额分别按币种求和，不做汇率换算。具体测试范围见[工作关单识别验证](recognition-validation.md)。

## 资源管理

批次、提取器与 OCR 引擎逐层拥有并释放下层资源。模型初始化失败、取消和图片解码失败都清理已取得的模型与图像对象；推理失败明确上报，不以空字符串伪装正常结果。PDF 打开失败释放库引用与固定内存。当前只运行 PP-OCRv5，旧双引擎合并流程已移除，历史复核属性仅用于兼容既有记录。
