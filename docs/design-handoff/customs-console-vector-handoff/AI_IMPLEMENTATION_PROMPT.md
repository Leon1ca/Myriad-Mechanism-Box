# 关单核验台：编码 AI 实现任务

请基于当前目录中的设计文件实现 Windows 桌面客户端界面与交互。不要重新设计视觉风格。

## 必读输入

1. `AI_UI_BUILD_SPEC.md`：单文件统一制作规格；参数冲突时以此文件为最高优先级真源。
2. `design/customs-console-ui.svg`：主界面视觉与组件层级。
3. `design/interaction-states.svg`：目录设置、清理确认和下拉展开状态。
4. `design/button-icon-spec.svg`、`assets/button-icons/`：五枚专用按钮图标及放大检视稿。
5. `design-tokens.json`：颜色、字号、间距、圆角、阴影与尺寸。
6. `prototype/index.html`、`prototype/styles.css`、`prototype/app.js`：语义结构和交互参考。
7. `README.md`：业务接口映射、数据模型和安全规则。

## 不可变要求

- 软件名称为“关单核验台”，名称和软件图标仅展示，不可点击。
- 主界面核心信息只能是关单统计与关单列表。
- 顶部操作依次为“目录设置”“关单清理”“截图清理”。
- 关单记录标题栏右侧依次为主操作“开始识别”和危险次要操作“列表清理”。
- 统计卡包含：本批关单、重复单号、去重前总价、去重后总价。
- 列表表头顺序必须为：序号、报关单编号、境外收货人、合同协议号、出境类别、目的国、关单总货值、状态、操作。
- 空列表只显示“暂无关单记录”，不要增加说明文字。
- 保持当前 Material 3 语义色与 8px 间距节奏，但实现形态必须是 Windows 企业桌面工具：深色应用标题栏、浅色命令栏、一体化统计总览条、高密度工作表格。
- 不得恢复彩色卡片左边条、深蓝大面积表头、厚重阴影或额外宣传文字。
- “开始识别”和“列表清理”必须使用同一按钮骨架：44px 高度、7px 圆角、24px 线性图标、1px 边框和一致的水平内边距；只通过主色与危险色区分。
- 所有带图标按钮必须将“24px 图标 + 10px 间距 + 文字”视为同一个内容组，使用 flex/grid 在按钮中水平、垂直双向居中；图标与文字不得依赖 baseline 对齐。
- 必须直接使用 `assets/button-icons/` 中对应的完整专用 SVG，禁止以通用文件夹、垃圾桶、播放键或扫描角标临时拼接替代。
- 关单记录标题区与筛选区仅通过 12–16px 留白建立层级，不绘制紧贴筛选标签的横向分隔线。

## 必须实现的交互

### 目录设置

- 点击“目录设置”打开模态弹窗。
- 弹窗分别设置“关单读取目录”和“截图保存目录”。
- 支持取消、关闭和保存。
- 保存后持久化到本机配置；重新打开弹窗时回显。

### 清理目录

- “关单清理”和“截图清理”各自使用独立确认文案。
- 用户确认后才允许清理。
- 执行前严格验证路径，拒绝空路径、磁盘根目录、用户主目录、程序目录及其上级目录。
- 默认优先移动到回收站；无法恢复的删除必须明确提示。
- 执行期间禁用对应按钮，完成后显示成功或错误反馈。

### 开始识别

- 未设置关单读取目录时，点击后打开目录设置弹窗并显示原因。
- 运行期间按钮变为加载状态并防止重复提交。
- OCR/核验任务必须在后台线程或异步任务中运行，不能阻塞 UI。
- 每产生一条记录即可增量更新表格；统计数据同步更新。
- 失败时保留已经成功解析的记录，并给出可重试的错误信息。

### 列表与筛选

- “列表清理”只清空当前批次的内存/界面数据，不删除源文件。
- 单号搜索建议使用 200ms 防抖。
- 记录筛选值：全部记录、正常记录、重复单号、核验异常。
- 每页数量：20、50、100。
- 下拉框支持鼠标、Tab、Enter、Space、上下方向键、Home、End 和 Escape。
- 筛选、搜索与分页状态在列表刷新后应保持。
- 表格数据行严格固定为 56px；长文本单行省略并提供查看完整内容的方式。
- 空状态时只保留表头列分割线，不得让竖线贯穿空白内容区。

## 建议架构边界

```text
UI / ViewModel
├── SettingsService
├── FileSystemService
├── RecognitionService
│   ├── OcrAdapter
│   ├── DuplicateChecker
│   └── VerificationAdapter
├── ScreenshotService
└── RecordRepository
```

- UI 不直接删除文件，也不直接调用 OCR SDK。
- 所有可取消的长任务使用取消令牌或等效机制。
- 业务服务返回结构化错误码和用户可读消息。
- 将路径、筛选、分页和识别状态写入明确的数据模型，不依赖控件文本作为状态源。

## 完成标准

- 默认窗口 `1586 × 992` 下与 SVG 视觉接近；列表必须获得剩余高度并贴合窗口右侧，统计总览不得挤占主要工作区。
- 所有可点击控件都有悬停、按下、焦点、禁用和加载状态。
- 普通文字对比度不低于 4.5:1；非文字边界和焦点状态不低于 3:1。
- 危险操作都有二次确认和失败恢复路径。
- 提供最少一组 UI/状态单元测试，以及目录安全校验测试。
- 构建产物可在 Windows 10/11 运行。
