# 千机匣 v0.2.1

适用于 Windows 10 / Windows 11 x64。完整解压便携包后运行 `千机匣.exe`。

## 关单识别

- 修复收货人文字框跨行时误取运输方式或生产销售单位的问题。缺失的收货人会提示核对。
- 合同协议号保留原文中的字母和数字，避免把字母 `O` 改成数字 `0`。
- 扫描件缺少收货人或商品金额时尝试调整识别分辨率，用能与原识别结果相互校验的字段补齐记录。
- 倾斜扫描件按商品栏和价格栏的表头位置对齐商品行，改善品名及规格漏读。
- 对有分栏标记的商品规格按图像中的竖线分段重读，保留已确认的分隔符和空字段。
- 主表和商品附加页按报关单号、原项号及商品明细核对重复项，内容相同的商品只计入一次，新增项继续累计；重复项内容冲突时提示核对并从可信合计中排除。
