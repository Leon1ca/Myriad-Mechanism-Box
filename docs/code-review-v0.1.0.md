# 整体代码审核与架构整理报告

日期：2026-10-10。版本：v0.1.0。本次以已完成识别优化的本地版本为基础，审查生产代码、测试工程、命令行及发布验证配置，并完成重构与缺陷修复。

## 审核结论

主要功能和识别规则保持一致。稳定性问题已按下面的验证范围修复；本次结果不代表所有异常环境均已覆盖。

## 已修复的问题

| 问题 | 处理 | 验证 |
| --- | --- | --- |
| 状态与导出各自实现保存，固定临时文件与并发替换存在冲突；保存失败未充分提示 | 统一原子写入，同路径串行化，唯一临时文件与刷盘；失败保留原文件，界面提示并允许取消退出 | 写入中断、临时文件清理、20 次并发写入、完整状态回读 |
| 旧历史中的空值、币种大小写变体与冲突值可能影响显示或金额 | 单独迁移层，规范化可选字段；相同币种金额去重，冲突金额排除并标记需关注 | 空值历史、冲突币种、旧复核字段往返及连续损坏文件备份 |
| OCR 模型部分初始化失败时的终结器可能访问未初始化资源；若干图片/模型对象未明确释放 | 显式可重复释放，失败路径清理；移除不安全终结器；推理失败向上传播 | 7 项原生资源测试，9 个实际 OCR 格式/旋转/多页文件 |
| PDF 读取或打开失败可能留下库引用或固定内存 | 读取与原生库取得顺序调整，构造失败统一清理，库计数加锁 | 缺失 PDF、损坏 PDF 前后原生引用计数一致 |
| 取消后仍可能接收迟到识别结果；进度回调异常可能被误记为另一条识别失败 | 提取完成后再次检查取消，缩小识别异常捕获范围 | 迟到结果拒绝、回调异常不生成第二条错误记录 |
| 浏览器关闭与命令注册、连接建立或界面回调存在竞争 | 通信关闭状态同步，命令覆盖全程超时，启动取消关联会话；界面检查会话和窗口有效性 | 8 项真实 WebSocket 通信测试，33 个受控浏览器场景 |
| 未知或缺少参数的自检命令可能意外进入界面 | 单一命令注册表校验参数，错误退出码 2，帮助入口 | 未知命令、缺参数及帮助检查 |

## 架构与冗余清理

源码按 Domain、Application、Recognition、Infrastructure、Browser、Export、Presentation、Diagnostics 整理。解析器、主窗体与浏览器核验按职责拆分文件；CDP 通信、历史迁移和原子保存独立维护。保留一个桌面程序集，避免增加不必要的服务或框架。

删除未被生产路径调用的双引擎合并器、第二引擎输入字段和旧外部 OCR 进程辅助类；移除闲置图标组件、旧确认弹窗、废弃字段控件及重复解析包装。旧历史复核属性集中保存，保持既有记录、详情和导出兼容。保留有效功能对应的测试，旧双引擎执行测试改为历史兼容验证。

## 后续维护与限制

实际单一窗口网站验证码、网站改版、Windows 10 和不同高 DPI 设备仍需现场验收。受控浏览器测试覆盖实现路径，不能替代真实业务网站验收。保留的 28 个构建警告来自第三方代码可空性及既有依赖版本引用；本次未进行依赖大版本升级。未做长时间内存压力测试。

新增通信、资源及命令行检查已加入 Windows 验证流程。审核后的源码用于初始化“千机匣”仓库；远端验证结果以本仓库 Actions 中对应提交的实际状态为准。
