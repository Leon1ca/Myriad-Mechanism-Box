# 千机匣 · Myriad Mechanism Box v0.1.0 正式版本说明

发布日期：2026-10-10。适用平台：Windows 10 / Windows 11 x64。发布形式：便携 ZIP。

v0.1.0 是关单核验台的新版本序列起点，以已确认的 1.5.3 源码和功能为基础，完成版本统一、正式文档整理及工作关单识别优化。主程序、启动器、文件版本、使用说明和发布包名称统一为 0.1.0。项目正式命名为“千机匣”，仓库地址为 `Leon1ca/Myriad-Mechanism-Box`，以本版完整源码初始化。当前桌面模块和启动程序名称继续使用“关单核验台”，保留用户数据目录兼容。旧仓库历史另行本地归档。

## 功能范围

- 本地读取 PDF 与常见图片格式，支持多页 PDF / TIFF、横放和倒置页面。
- 识别报关单号、境外收货人、合同协议号、出境关别、目的国及逐币种总货值。
- 查看商品名称及规格、原页计价数量、单位、单价和总价明细。
- 检测本批重复关单，分别汇总去重前和去重后金额；支持搜索、筛选、分页和单元格复制。
- 导出 Excel 关单列表、关单明细、币种汇总三张表，或导出 Markdown；导出覆盖整批记录。
- 用户在单一窗口查询页人工输入验证码并查询后，通过网页卡片保存完整长截图。
- 提供列表、关单及截图独立清理；文件清理经过两次确认，仅处理当前层并移入回收站。

## 识别优化

- 修复文字框稍跨入下一单元格时收货人被遗漏的问题，按字段标签和文字中心定位。
- 商品名称剔除混入的十位商品编码，并过滤斜向大字水印，避免水印数字拼入单价或总价。
- 修正商品行起点与项号定位，避免串入下一商品行，兼容续页和轻微的文字基线偏移。
- 补齐“条”“床”“把”等常见单位。数量和单位始终从同一原页文字组合读取；优先选择与单价和总价一致的实际计价数量，不通过金额倒算数量。
- 按单价实际印刷小数位允许合理舍入误差，不用总金额比例掩盖金额错字。PDF 文字层与 OCR 均执行金额规则。
- 商品表出现漏项或无金额时，使用同一 PP-OCRv5 引擎补扫局部，补充缺失文字；不覆盖冲突的已有识别值，不推测币种。
- 检查每页可定位商品行与已识别金额项数，漏项会提示核对完整性。
- 对可明确识别的提单、放行通知等非关单文件给出专门提示，不将其字段或金额计入关单合计。

## 架构与稳定性

- 按识别、批次、数据、存储、浏览器、导出和界面整理代码；删除未使用的双引擎执行逻辑与闲置界面组件，保留旧历史读写兼容。
- 历史和导出统一原子保存；修复并发写入冲突，保存失败明确提示，退出时可取消关闭。
- 完善 OCR、PDF 和图像对象在正常、失败与取消时的资源释放。
- 修复浏览器关闭期间的命令等待、连接与界面回调竞争，拒绝失效批次的迟到结果。
- 集中命令行参数校验；错误参数明确退出。

## 安装和数据

完整解压 ZIP 后，运行根目录 `关单核验台.exe`；不要在压缩包中直接启动。识别历史和日志仍保存在 `%LocalAppData%\关单核验台`，建议更换程序前备份该目录。已有记录需要重新识别才能获得本版规则结果。

发布包包含 .NET 运行时、PP-OCRv5 模型、PDFium、字体与第三方许可，不包含真实关单、识别报告、用户配置或历史数据。文件校验值见同一发布页的 `SHA256SUMS.txt`。

## 使用边界

每批最多 200 个文件。严重模糊、裁切、遮挡和不完整页面仍需人工核对；未知字段保持空白，异常项目显示“需关注”。可信合计不包含金额规则不符的项目，不能将部分合计当作完整货值。真实网站验证码由用户完成，网站改版和实际查询流程仍需现场验收。Windows 10 及各档高 DPI 显示仍应在目标设备验收。
