# 千机匣 · Myriad Mechanism Box v0.2.0 版本说明

发布日期：2026-10-10。适用平台：Windows 10 / Windows 11 x64。发布形式：便携 ZIP。识别规则、导出格式和历史数据与 v0.1.0 兼容。

## 名称与图标

- 软件正式名称统一为与仓库一致的“千机匣”（Myriad Mechanism Box），原名“关单核验台”。窗口标题、标题栏、提示框、网页截图卡片、使用说明和文档均已更新。
- 程序入口改为 `千机匣.exe`，发布包命名为 `MyriadMechanismBox-Windows-x64-v0.2.0.zip`。
- 首次启动时把 `%LocalAppData%\关单核验台` 中的历史记录、设置、日志和核验浏览器配置整体迁移到 `%LocalAppData%\千机匣`，旧数据不会丢失。
- 更换为新的唐门面具图标：程序文件、任务栏、窗口与标题栏统一使用；标题栏按显示缩放选取对应分辨率，高 DPI 下依然清晰。

## 列表与明细

- 记录列表不再显示来源文件名，单号列只显示 18 位报关单号并垂直居中；重复记录在单号下方标注“合计代表 / 不计入”。搜索范围相应调整为单号、收货人和合同号。双击记录仍可打开源文件。
- 商品明细只保留商品名称、数量、单价、总价四列：名称最多两行显示，数量附带单位，金额右对齐并标注币种；底部按币种列出合计及校验结论。明细窗口加宽到 680×500。
- 金额汇总的未确认金额提示不再附带文件名。

## 界面细节

- 记录区工具栏与表头、表格与分页栏之间增加分隔线；金额汇总表头上下沿、币种行之间增加细分隔线。
- 选中单元格时保留行分隔线；不再默认高亮第一行的序号格。
- “明细”“校验”按钮描边按半像素对齐，边缘更清晰。
- 弹窗外框不再被内部区域遮挡，四边边框完整可见。

## 刷新闪屏与性能

- 识别过程中、筛选、翻页、截图回填时不再整表清空重建，改为原地更新行，滚动条与列宽不再跳动；识别中保持当前滚动位置。
- 工作区的统计、表格、筛选在一次刷新内合并为一次重绘；内容未变化的面板不再重绘。
- 开始/取消按钮图标只在状态变化时替换；最大化、还原时整体一次重绘；窗口尺寸不变时跳过重复布局。
- 表格与面板绘制复用字体、画笔、画刷与图标，降低重绘开销。

## 网页核验浏览器

- 核验窗口与系统中的 Edge 是同一程序，但出于浏览器安全限制必须使用独立配置，无法显示日常配置的账户、收藏夹和扩展。
- 此前每次核验都新建一个空白配置，因此看起来像“另一个浏览器”。现在交互核验复用数据目录中的固定专用配置，保留缩放、站点权限与网站 Cookie，后续打开更快；并发窗口自动分配，占满时回退为一次性配置。
- 不再开放 `--remote-allow-origins`，调试连接只接受本程序；关闭时先正常退出浏览器，不再出现“恢复页面”提示。

## 代码与仓库

- 删除历史设计稿、旧版交接资料、整体审核报告、手工浏览器回归页、Linux 便携 E2E 工具与已不使用的旧图标；删除未引用的代码成员与多余命名空间引用。
- 文档更新为 v0.2.0，架构说明补充刷新机制、核验浏览器配置与维护要点。
