# 关单核验台：企业风 UI / UX 重设计

基线：当前 `main @ cc1ae62`，正式版本 1.4.0。设计工具：按用户确认使用本地 `design` 与 `ui-ux-pro-max` 技能。交付是可供开发落地的设计提案，不是已经编译替换的 Windows UI。

## 设计取舍

高级企业风通过克制的深海军蓝、浅灰工作背景、清晰的表格层级与统一图标实现。保留项目原有应用标志，不新增导航侧栏、经营图表或无关模块。技能检索提供的营销页面、徽章和动画建议与此工作台不符，未采用；保留其对比度、清晰表格、语义色和键盘可达性的建议。

把界面划分为：应用标题栏 → 工作台主操作 → 当前目录 → 本批汇总 → 记录与筛选 → 表格 → 分页。关单号、金额和异常状态是阅读中心。

## 功能与新布局映射

| 当前功能 | 新布局 / 交互 |
|---|---|
| 开始识别、取消识别 | 右上方唯一实心主按钮。识别中显示独立进度条、当前文件、完成数量和取消入口 |
| 目录设置 | 读取目录、截图目录直接展示；右侧统一“目录设置”弹窗 |
| 本批文件数、重复组数 | 两张紧凑统计卡；重复卡可直接筛选重复记录 |
| 去重前后多币种合计 | 合并为对比表：币种 / 去重前 / 去重后，同币种处于同一行，避免跨卡来回查找 |
| 状态筛选与单号搜索 | 带数量的筛选按钮 + 右侧单号搜索；筛选仅改变记录列表，本批统计保持不变 |
| 6 个业务字段 | 保留单号、收货人、合同协议号、关别、国家、总货值；单号下增加源文件名用于区分副本 |
| 重复单号 | 行首细红标识 + 文字徽标；保留重复置顶；不把整行文字全部染红 |
| 识别异常 | 独立“需关注”徽标；可与“重复单号”和“已留存”同时出现 |
| 逐单在线核验 | 固定语义为“核验/重核验”；分三步显示打开网页、人工查询、截图留存，保留 90 秒超时兜底 |
| 核验截图完成 | 单独标记“已留存”，不宣称海关放行，也不遮挡识别异常 |
| Markdown 导出 | 次级按钮；导出范围是本批全部，含隐藏分页、筛选隐藏和重复记录；正式导出继续保留逐项价格、复核值与未确认提示 |
| 列表 / 关单 / 截图清理 | 集中于“清理”菜单并分别解释范围；列表清理不删文件；文件清理显示路径、数量、类型并二次确认 |
| 空列表、无搜索结果 | 分开提示，分别提供开始识别与清除筛选；保留拖入文件的入口语义 |
| 复制与查看源文件 | 选中单元格复制；双击原文件；原生实现继续支持多选、右键单项复制、双向拖动列宽 |

“需关注”和“重复”允许重叠，所以筛选数量不一定相加等于总数。汇总金额只包含现有规则确认的金额，未确认分项不计入；以固定提示说明部分金额需核对完整性。

### 字号、空间与密度

- Windows 使用 Microsoft YaHei UI / Segoe UI；网页原型在 macOS 回退至 PingFang SC。单号、合同与金额使用等宽或等宽数字，金额右对齐。
- 页面标题 25 px，区域标题 17 px；核心表格 13–14 px，单号与金额 14 px；辅助源文件名和状态徽标 11 px。低优先级预览辅助区可更小，不用于业务关键字段。
- 4/8 px 间距体系，主要外边距 32 px，窄桌面 22 px；主按钮高 42 px，记录行约 66 px（含两行标识），圆角 7–10 px，避免大面积阴影。
- 长公司名可换为两行；单号完整显示，避免以省略号隐藏 18 位编号；合同号可横向扩列，悬浮显示全文。
- 多币种汇总使用自适应高度，超过三种币种时不得覆盖下一行，也不得变成汇率换算后的单一总额。

### 图标

22 个统一线性 SVG，24×24 网格、1.75 px 描边、圆角端点；分别提供 24/32/48 px 透明 PNG。图标与按钮文字并列，主要功能不依靠纯图标猜测。

保持源文件原有标志。图标包位于 `assets/icons/`；为桌面主色示例资源，实际渲染需按按钮语义生成白色/危险色版本或使用可着色矢量绘制，不能把深色 PNG 直接放进深色主按钮。

## 状态与边界

| 状态 | 允许 | 禁止 / 提示 |
|---|---|---|
| 未开始 | 设置目录、开始识别、拖入文件 | 无数据禁止导出；提供支持格式与 200 文件上限 |
| 预检不通过 | 调整目录或文件 | 保留旧批次，不提交空历史 |
| 识别中 | 查看已完成结果、搜索、取消 | 禁止导出、清理、切换批次；目录变更应延后至会话结束 |
| 已完成 | 搜索、筛选、分页、复制、导出、逐单核验 | 异常状态不因截图或重复分析被抹除 |
| 核验等待 | 在浏览器人工验证码查询、关闭 | 不自动绕过验证码；等待结果稳定且身份一致 |
| 核验超时 | 核对网页后手动截图、关闭 | 不宣称核验已通过 |
| 清理源文件 / 截图 | 预览范围 → 二次确认 → 移回收站 | 禁止根目录，禁止递归或永久删除；保留失败文件并报告 |

主按钮状态统一来自批次会话，而不是每个按钮单独判断。

## 原生落地建议

沿用 .NET 8 WinForms，不要求迁移网页技术栈。用 TableLayoutPanel 分区、DataGridView 保留数据操作，主题常量与组件分开维护。

1. `MainForm.Layout.cs`：布局、目录条、汇总对比组件、表格工具栏；用可伸缩宽度替换固定的 412/293/245 筛选区。
2. `RecordStatusPresenter`：识别、重复、截图三维映射；不得继续拼接覆盖同一个 Status 字符串。
3. `ScanSession`：预检、进行中、取消、完成与统一按钮状态；数据稳定后再绑定 UI。
4. `VerificationForm`：三步反馈、超时解释、留存结果；网站脚本须先补齐结果单号校验。
5. `CleanupPlan` 与清理弹窗：显示实际目录与候选清单数量，第二次确认使用同一份计划。
6. WinForms 图标在当前窗口 DPI 上选档/渲染；跨显示器切换重新计算，不能只依赖进程启动时的单个全局 DPI。

## 原型实现与验证边界

原型实现：筛选、搜索、汇总、单元格鼠标多选与复制、演示识别/取消、目录输入、核验等待/模拟结果/超时、清理菜单/双确认、示例 Markdown 导出、窄窗口横向表格滚动。页面底部明确标记“示例数据”。

不执行真实 OCR、真实文件夹浏览、删除文件或访问核验官网。示例导出只含展示字段，正式分项导出继续使用现有 C# 导出器。分页控件保留 20/50/100，示例仅 20 条，因此当前没有第二页；双向列宽拖拽、右键复制菜单与真实文件打开属于原生落地验收项。原型不等同已完成这些原生功能。

已检查 1600×1000 主界面、1200×800 窄桌面、375×812 小屏框架；1200 宽度保留表格内横向滚动，未出现整页横向溢出。375 小屏仅用于可访问预览，不扩展桌面产品的平台承诺。支持减少动画偏好、可见焦点、标签与非颜色状态表达。
