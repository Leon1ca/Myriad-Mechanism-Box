| `icons/png/` | PNG 16/24/32/48 | 按用途预着色，命名 `图标-颜色-尺寸.png`，对应 100% / 150% / 200% / 300% DPI。 |

| `fonts/FONTS.md` | Markdown | 字体下载、放置目录、OFL 许可说明。 |
| `source/` | `.dc.html` + `canvas.json` | 画布设计稿源文件，存档用，需在 Claude 设计画布中打开。 |

## 建议接入顺序

1. 按 `fonts/FONTS.md` 下载字体放入 `app\fonts\`，许可文本放入 `third-party-notices/`。
2. 把 `code/` 两个文件加入 `src/CustomsClearanceConsole/Ui/`，调整命名空间；`Program.Main` 开头调用 `AppFonts.Initialize()`，并确认 DPI 模式为 PerMonitorV2。
3. `icons/app/app.ico` 设为 `ApplicationIcon`；所需 PNG 加入资源。
4. 主窗体：按规范第 2 节重排（无侧栏、顶栏仅“设置”、导出与清理改为下拉、表格新增“查看”列、每页条数改为自绘下拉），在 `ClientSizeChanged` 中调用 `Responsive.Compute` 应用第 9 节规则。
5. 实现三种空/过程状态：未载入、待识别、识别中（规范第 2.4、2.5、6、7 节）。
6. 新增弹窗：明细、设置、清理确认（两次点击）。
7. 网页核验改为注入 `web/capture-widget.html` 中的悬浮卡片，删除程序内核验对话框。

## 相对 v1.4 的变化

- 删除左侧栏；目录设置收进顶栏“设置”弹窗；删除“使用说明”“关于与许可”入口和说明性提示文字；删除列设置按钮。
- 导出改为下拉：导出为 Excel（.xlsx）/ 导出为 Markdown（.md）。
- 清理改为记录区下拉；文件清理两次点击确认，不显示文件列表。
- 表格新增“查看”列，“明细”弹窗显示逐项价格（只读）。
- 每页条数改为与整体风格一致的向上展开下拉。
- 新增未载入、待识别两种空状态的填充设计。
- 右键复制：选区高亮、单项菜单、“已复制”提示。
- 网页核验改为网页内悬浮“长截图”按钮。
- 识别中不显示引擎阶段。
- 窗口缩放：纵向只伸缩表格行，高度 < 820 进入紧凑密度；横向分档并按规则压缩 / 合并表格列。
- 字体全部改为开源：Noto Sans SC + JetBrains Mono。

## 说明

- 效果图在离线环境渲染：中文字形与 Noto Sans SC 相同（Noto Sans CJK SC），等宽数字暂用 DejaVu Sans Mono 代替 JetBrains Mono，数字字形略有差异，尺寸与布局一致。
- `code/` 中的 C# 为参考实现，未在本环境编译，接入时请按项目实际结构调整。
- 规范中“手动拖过的列宽保持、双击分隔线恢复规则宽度”“导出不受筛选影响”“每页条数记住用户选择”为设计建议，如与现有行为冲突以现有行为为准。
