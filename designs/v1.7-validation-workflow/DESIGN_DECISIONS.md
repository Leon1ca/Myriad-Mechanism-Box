# v1.7 设计决策

## 1. 推荐的核验流程

### 主路径：一次点击，人工只处理验证码

1. 用户在关单列表点击“校验”。
2. 软件使用系统默认 Edge/Chrome；若默认浏览器不支持自动控制，则自动使用已安装的 Edge，再回退 Chrome，不再让用户选择。
3. 打开 `https://www.singlewindow.cn/#/publicInquiryDetail?id=pi4`，自动填写报关单号。
4. 软件显示轻量悬浮状态卡“等待人工验证码”，不使用阻塞弹窗。
5. 用户在网页输入验证码并点击“查询”。
6. 软件通过浏览器调试协议监测页面：加载结束、结果区域出现、内容连续稳定至少 1.2 秒。
7. 软件自动展开网页内部滚动容器、生成完整长截图，并以报关单号命名。
8. 应用列表状态改为“已截图”，右下角显示非阻塞成功通知，可选“打开截图”。

相比现状，删除“回到软件”“点击已填写”“再次确认保存”三步。

### 降级路径

- 90 秒仍未检测到结果：悬浮卡显示“仍在等待”，提供“立即截图”和“重新检测”。
- 网页结构变化：按“结果特征”而非单个 CSS 选择器检测；若仍失败，保留“立即截图”。
- 浏览器控制连接中断：不丢失用户已打开的网页，提示使用浏览器网页捕获，并给出目标文件名。
- 截图失败：保留本次核验上下文，可重试截图，不要求重新输入验证码。
- 同一报关单已有截图：保留旧文件，新文件追加时间戳。
- 验证码只由用户输入；软件不识别、不绕过、不代填验证码。

## 2. 右键复制菜单

- 自绘无边框弹层，宽 224px，圆角 8px，1px `#C2C7CF` 边框，菜单阴影 `0 8px 24px rgba(16,42,67,.16)`。
- 只保留一个 46px 高的菜单项：“复制选中的内容”，右侧显示 `Ctrl+C`。
- 不显示选择数量、复制图标或说明文字，避免单一操作菜单显得臃肿。
- 支持右键、Shift+F10、菜单键和 Ctrl+C；焦点样式不可只依赖颜色。
- 复制成功只显示 1.5 秒轻提示，不弹 Windows 消息框。

## 3. PNG 图标策略

- 保留可编辑母版，但客户端加载逐尺寸 PNG，不在运行时用 GDI+ 重画。
- 提供 24/32/48px 三档；按 Windows DPI 选择最接近的一档，禁止拉伸。
- 使用主流圆角线性图标语言：24px 基准网格、约 1.65px 常规描边、圆角端点、单一含义与小型实心状态徽标。
- 所有外轮廓内缩至少 3px；关键水平线使用一致厚度；清理类图标统一使用红色实心圆形 `×` 徽标。
- 目录设置与开始识别使用蓝色；三项清理使用红色；主按钮另有白色“开始识别”版本。
- 图标只是按钮内容，不替代按钮文本和无障碍名称。

## 4. 关单概览信息层级

- 指标标题为 17px/600，使用主级深灰；标题是卡片的视觉主层级。
- 件数与组数仍为 30px 强调字重；用于快速扫描数量。
- 金额为 15px/400，使用次级深灰且不加粗；作为标题下方的信息内容显示。
- 标题到金额使用 8px 间距，四张卡片保持同一基线与节奏。

## 5. `HNB_TX_US` 修正规则

样本 PDF 文本层将 `HNB`、`TX`、`US` 放在正常字母行，将两枚 `_` 作为高度仅约 0.2pt、位置更低的独立字符。当前行聚类把 `_` 分到下一行，最终得到 `HNB TX US _ _`。

建议修正：

- 对 `_`、`-`、`.`、`/` 等连接符使用“水平关系优先”的回接规则。
- 当低位连接符位于两个 ASCII 标识片段之间，且 X 方向间距匹配时，按 X 坐标插回原字符串。
- 仅在结构化标识字段（境外收货人代码、合同号等）中启用，避免误拼普通自然语言。
- 新增固定回归：`7063(1).pdf` 的境外收货人必须为 `HNB_TX_US`，同时总值保持 `CNY 346,940.00`。

## 6. 进入功能迭代后的验收点

- 100%、125%、150%、175%、200% DPI 下五枚图标上下线条一致且无裁切。
- 右键菜单位置不会越过屏幕工作区，键盘可完成全部复制操作。
- 人工验证码完成后无需回到软件，正常情况下自动截图。
- 超时与网页改版不会卡死，用户始终有“立即截图”降级入口。
- 截图保存成功后，表格状态和文件路径同步更新。
- `7063(1).pdf` 回归输出 `HNB_TX_US`。
